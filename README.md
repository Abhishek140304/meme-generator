# 📖 Project Overview

**Meme Generator** is a simple and fun web application that allows users to create custom memes in real time.

The application fetches meme templates and lets users:

- Add custom top and bottom text.
- Generate random meme images.
- Preview changes instantly.
- Create unlimited meme combinations.

This project demonstrates:

- API integration
- React state management
- Event handling
- Controlled components
- Dynamic UI rendering

---

# ✨ Features

## 🎲 Random Meme Generator
- Generates a random meme template with a single click.
- Picks from a large collection of meme images.
- Every click provides a different meme.

---

## ✍️ Custom Text Editor
Users can:

- Add text to the top of the meme.
- Add text to the bottom of the meme.
- Instantly preview text changes.

---

## ⚡ Real-Time Updates
The meme updates immediately whenever:

- The user types text.
- A new template is selected.

No page reload is required.

# ⚙️ Installation and Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Abhishek140304/meme-generator.git
cd meme-generator
```

---

## 2️⃣ Install Dependencies

```bash
npm install
```

---

## 3️⃣ Start Development Server

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```
