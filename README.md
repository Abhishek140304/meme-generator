# 🤣 Meme Generator

A React-based meme generator that fetches trending templates from the Imgflip API, allowing you to add custom top and bottom text dynamically.

## ✨ Features
- **API Integration:** Retrieves popular meme templates from the [Imgflip API](https://api.imgflip.com/get_memes).
- **Random Selection:** Easily generate a new template with the click of a button.
- **Live Preview:** See your custom text applied to the meme in real time.
- **React Hooks:** Built using `useState` for handling text/image state and `useEffect` for data fetching.

## 🛠️ Tech Stack
- **Frontend:** React (Vite/Create React App)
- **Data Fetching:** Native `fetch` API
- **Styling:** Vanilla CSS
